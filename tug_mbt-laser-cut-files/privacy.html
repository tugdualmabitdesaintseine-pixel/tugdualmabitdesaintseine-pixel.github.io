tug_mbt autopin – Privacy Policy

Last updated: 4 November 2026

“tug_mbt autopin” is a private tool used only by its owner, the designer tug_mbt, to publish Pins of his own laser-cut design files (images, videos and links to his pages on Cults3D) on his own Pinterest business account. It is not offered to any other user.

Data accessed

With the owner’s authorisation (Pinterest OAuth), the tool accesses only the owner’s own Pinterest account: account name, list of boards, and the Pins it creates. It requests the scopes boards:read, boards:write, pins:read, pins:write and user_accounts:read.

Use of data

This data is used solely to create Pins on the owner’s board “Laser Cut Files” and to avoid publishing the same Pin twice. No data from other Pinterest users is collected. No data is sold, shared with third parties, or used for advertising.

Storage and security

The access token is stored encrypted in the owner’s private code repository and is used only by automated jobs run on the owner’s behalf. Identifiers of the Pins created are stored with the design files. Access can be revoked at any time from the Pinterest account settings (Security › Connected apps).
